# Salón by Kristel · propuesta de web (demo)

Demostración de una web nueva para **Salón by Kristel** (peluquería de corte y color, Castelló de la Plana).
Es una **propuesta de diseño**, no el sitio oficial: https://salonbykristel.com

**Ver la demo:** https://sefiro888.github.io/salon-by-kristel-demo/  ·  Inglés: https://sefiro888.github.io/salon-by-kristel-demo/en/

- Web estática (HTML, CSS y JavaScript propios, sin frameworks), en español e inglés.
- Contenido, precios y horario de su ficha de Booksy; fotos y vídeos de su Instagram (@salonbykristel).
- La imagen de portada del inicio es **ilustrativa** (no es un trabajo real del salón).
- Esta demo está marcada como `noindex`: no se indexa en buscadores.
- Para verla en local: `python -m http.server 8000` y abrir http://localhost:8000
